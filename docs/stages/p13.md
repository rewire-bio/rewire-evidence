# P13: KG export, attribute terms, draft block, and SHACL validation

**Issue:** `rewire-bio/rewire-evidence#13`
**Oracle:** `rewire-benchmark-data` at `91f76cf8e61cba9d6037a01a19c9aa3051184900`

## What was ported

- `kgterms.py`: `camel`, `attribute_property`, `encoding`, `attribute_uses`, `declarations_turtle`, and `shapes_turtle` from `scripts/kg/attribute-terms.ts`.
- `kgdraft.py`: `draft_block`, `attribute_schemas`, and `TYPE_SCHEMAS_FILE` (`data/attribute-type-schemas.json`) from `scripts/kg/draft-block.ts`.
- `kgexport.py`: `iri`, `canonical_decimal`, `build_context`, `record_quads`, `export_quad_lines`, `subset_quad_lines`, `write_quads`, `export_store`, `export_subset`, `write_context`, `write_terms`, and `write_draft_block` from `scripts/kg/export.ts`.
- `kgshapes.py`: `load_ontology`, `load_asserted`, `graph_from_lines`, `infer`, `check_inferred`, `without_inferred_paths`, `shard_shapes`, `validate_shapes`, `shapes_only_check`, and `parse_shard` from `scripts/kg/build.py` (SHACL and OWL 2 RL subset and build validation via `rdflib`, `owlrl`, and `pyshacl`).
- `kgpublish.py`: immutable GitHub release tarball packing and verification (`uvx rdf-kg-mcp` + `gh release`) from `scripts/kg/publish.ts`.
- `kgparity.py` and `scripts/verify_store_kg.py`: full-store N-Quads parity gate plus recorded P5/P6 subset and SHACL checks.
- `writes.py` (`shapes_check`) and `cli.py` (`kg context|export|terms|subset|draft-block|shapes|publish`): in-process SHACL verification for `records add` and `records change` with zero Node or `npm` subprocess calls.

## Measured parity against `91f76cf8`

- Full N-Quads export: **2,445,824 asserted quads** across **93,216 records** (**92,746 public**), **49 / 49** 50,000-line chunk SHA-256 digests, and full `asserted.nq` SHA-256 match `export.ts` byte for byte.
- Generated ontology artifacts: `context.jsonld`, `rb-attributes.ttl`, `attribute-shapes.ttl`, and the manifest `draft` block match `export.ts`, `attribute-terms.ts`, and `draft-block.ts` byte for byte.
- Subset export and `--shapes-only` verdicts: **36 / 36** recorded cases (**24** P5 validator cases and **12** P6 write cases) reproduce `subsetQuadLines` and `build.py --shapes-only` identically.
- Source module pin: all **4 / 4** TypeScript/Python KG modules match the SHA-256 digests recorded in `scripts/expected/store-kg.json`.
- Write path: all **117** recorded write-path cases run with `PATH=""` (Node-free). The 4 synthetic cases whose post-write store violates `load_records` or SHACL (`change: a record edited and not named`, `change: a record edited into one the store's rules refuse`, `change: a record edited into another kind`, `changes: a record changed into one the store's rules refuse`) fail SHACL/store validation and restore the store cleanly.

## Intentional differences and boundaries

- `writes.shapes_check` validates subset N-Quads in memory via `subset_quad_lines`, `graph_from_lines`, and `shapes_only_check` instead of writing a temporary subset directory and calling `npm run -s kg` and `npm run -s kg:build`.
- `contradictions.ts` (editorial discrepancy rules) and the post-`91f76cf8` bundle modules (`release_graph.py` and `product_queries.py`) are outside P13.
- `rdf-kg-mcp pack` / `verify` invocation in `kgpublish.py` keeps the external CLI boundary (`uvx --from ... rdf-kg-mcp` and `gh release`) because packaging the tarball format lives in `rdf-kg-mcp`.
