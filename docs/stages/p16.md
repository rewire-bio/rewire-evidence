## What was built

- `__init__.py`: exports `__version__` (`0.1.0`) matching `pyproject.toml` distribution metadata.
- `batch.py`: extracts the shared core from the 42 copies of `extract/lib.py` (`11` drifted SHA-256 hashes across `148` Python batch folders, `412` `.py` files, `114,117` lines):
  - `slug`: ASCII kebab-case normalisation matching historical `+`, `%`, Greek, and combining mark rules.
  - `num` and `sha` / `sha256`: printed number parsing (preserving decimal strings and Unicode minus handling) and file digest helper.
  - `extraction_review` and `write_review_receipt`: stamps `package` (`"rewire-evidence"`), `package_version`, `producer` (`"rewire-evidence==0.1.0"`), and SHA-256 digests of every non-receipt file in the batch directory.
  - `Batch` (`rid`, `facets`, `add`, `source`, `entity`, `evaluation`, `result`, `claim`, `judgement`, `write_links`, `write`): emits sorted `batch.jsonl` via `canonical.js_stringify` (`utf16_key` order) and sorted `claims.csv`.
  - `finalise`: captures `batch_sha256_before_review`, marks `source_checked` or `disputed`, writes reviewer provenance blocks, validates every record via `schema.parse_record`, writes `review.json`, and delegates store writes to `writes.plan_add` and `writes.write(..., check=writes.shapes_check(store_root))`.
- `batchparity.py` & `scripts/verify_store_batches.py` (`gates.batches_gate`): measures all `199` `data/omics/` directories (excluding `audits` and `layers`), validates all `64,132` committed `batch.jsonl` rows against `schema.parse_record` and `data/provenance/records/`, executes self-contained builders safely in isolated temporary copies (`python3 -I`, AST-blocking network-importing scripts), reports per-wave match rates across all 14 waves, and lists every non-reproducing batch with its reason.
